# Team materials

Everything in this folder is listed at `/team` (password-protected when hosted).
Drop a file in, reload the page. Subfolders are fine. Files and folders starting
with `.` or `_` are hidden.

| File type | Shown as |
| --- | --- |
| `.md` | Rendered page. Optional frontmatter: `title`, `description`, `tags`, `author`, `updated`. |
| `.html` | Standalone page, opened as is. Add `<meta name="description" content="...">` (also `author`, `tags`, `updated`) to describe it. |
| `.pdf`, images, video, `.csv`, `.pptx`, ... | Opened or downloaded. |
| `_links.yaml` | Artefacts that live elsewhere (claude.ai, Google Docs, Figma). |

No secrets, passwords, phone numbers or private emails: the repository is shared.
