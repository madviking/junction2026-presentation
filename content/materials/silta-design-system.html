Silta · team reference

Silta Design System

One system for deck v3 (/presentation) and the pitch video. The CSS lives in app/static/deck-v3.css; this page uses the same file, so what you see here is what the deck renders. Slide content is in content/presentation-v3.yaml.

Rules

  • One sentence per slide. A title and one line. Everything else goes into a drill-in.
  • At most three numbers in view, and every number has a source in its drill-in or the foot. Sources name the publisher or study (10 px mono), never a file path.
  • Screens are always real and always in a frame: phone, browser or paper.
  • Nothing moves position between slides. Kicker, title, path, chips and source always sit in the same place.
  • Colour means something (below). Never use coral or moss as decoration.
  • No emoji, no icons as decoration, no gradients except the drawer.

Type: three families, eight sizes

Bricolage Grotesque for titles and numbers, Atkinson Hyperlegible for reading, IBM Plex Mono for labels and sources. Sizes are for the 1280×720 slide; multiply by 1.5 for 1920×1080 video.

The frame

Every slide is 1280×720 with margins 56 top, 72 sides, 36 bottom, and four regions. Spacing uses one scale: 8, 16, 24, 32, 48, 64.
